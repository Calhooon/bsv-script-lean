[D] HashCommits is injectivity of the executable SHA256d on the finite
concatenation of pathInputs for the external path and canonical body path.
It is a hypothesis, never an axiom. Path shape requires an in-range index,
equal branch depth, and 32-byte leaves/siblings, with non-null canonical
literals and successful supplied-path verification against the header root.
AuthenticatedBody explicitly
binds active[height], index lookup, height, retained body, header equality,
header root/body-root equality and mutation false. Exact Tx membership names
additional txid injectivity over the supplied Tx and body transactions.
The reference's unsigned-index domain is below [D] 2^32; the Nat API is a
total extension above that domain.

[D] Qualified forms and gaps: mutation false alone does not prove canonical
branch literals non-null. The pin interprets every null sibling as a
working-hash duplicate before inspecting the index bit; literal zero hashes
from ComputeMerkleBranch need that explicit restriction. Unrestricted literal-branch completeness over raw hash lists is false in
general, rather than an owed unconditional proof. Non-null literals are a
sufficient compatibility restriction, not necessary for every branch and
not a block-acceptance rule ([SRC] src/validation.cpp:5770-5781 at 6504a3af).
For example [D] leaves [32 copies of byte 01, zero32], index 0, are unmutated
but literal and marker-expanded roots differ. This is a raw-hash example,
not a constructed zero-txid transaction. Raw Tx records can have truncated wire
fields, so exact structural Tx identity additionally needs the stated txid
injectivity premise. #64's ChainState type contains missing/pruned bodies and
does not enforce a global header/body validation invariant; AuthenticatedBody
is a local well-formedness hypothesis, not an invariant-preservation theorem.
The negative universal theorem uses the raw-state countermodel. The stronger
nonempty accepted-block/invalidate witness is checked executably on #64's
assumed intake prefix, not proved as a reachable-state existential. That
prefix's historical bodies remain assumed in the Lean run; the fresh node
run separately scans every actual active body. These are the limits of the
landed forms, with no placeholder proof.
