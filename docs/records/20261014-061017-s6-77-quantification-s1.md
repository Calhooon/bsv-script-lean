## What was audited, and how [M]

The four inputs #77 names are the slots `params : ChainParams`, `cfg : NodeConfig`, the oracle
(`ScriptOracle`) and `now`. `tools/specgen.py` (new functions `statement`, `binders`, `chain_bundles`,
`fixture_fixes`, `quantification`, `chain_quantification`, `quant_line`, `quant_summary`) reads each
theorem's statement from the masked source and decides, per slot:

- **every**: a binder of the slot's type (`ChainParams`, `NodeConfig`, `ScriptOracle`, a binder named `now`),
  or of a chain-layer structure carrying it, read from the sources (`ChainContext`: params, cfg, now;
  `AdmissionContext` and `UtxoContext`: params, now), or a named inductive predicate whose constructors bind
  it (`Reachable`: every step's `ChainContext` and oracle are the constructor's arguments);
- **fixed**: the statement names a network's record (`ChainParams.mainnet`, `.regtest`, `.testnet`, `.stn`,
  the network tables `NetworkData`/`DepthNetwork`), the census defaults `NodeConfig.defaults`, the evaluator
  `evalOracle` or a literal `now :=`, directly or through a chain-layer definition whose body does (closed
  under the definitions it names: `staleRunContext` fixes all four, every stale-run definition built on it
  inherits them); a slot both bound and fixed is fixed;
- **·** (absent): no function of the statement takes the slot. In Lean a definition reads only its
  arguments and global constants, so an absent slot is a slot the statement's functions do not read, except
  through a default argument or a structure field's default, which the lint below names.

A theorem is **quantified** when no slot is fixed and at least one is bound, **free** when none of the four
is an argument, **fixed** otherwise. A fixed theorem's warrant is read too: the general form its explainer
names in a sentence "The general form (or equivalence) is `name`", accepted only when `name` is a chain-layer
theorem that fixes no slot (quantified, or free of the four); else the concrete run it states (a closed definition of its own Properties file named in
the statement); else the explainer's "by design"; else FLAGGED. The same functions print each theorem's
quantification line on `spec/theorems.md` and the count on `spec/README.md`.

## The walls

- The classifier is lexical over the masked source, not Lean elaboration: it reads binder types by name
  (`ChainParams`, `BsvChain.ChainParams`; the script layer's `BsvScript.Params.ChainParams` is a different
  type and is not a slot), a `now` slot only by the binder's name, and predicates' constructors by type. A
  time input named otherwise (`isFinalTx`'s `time`, the cutoff) is not `now` and is not counted as one.
- A slot read through a default (a default argument, such as `medianTimePast`'s span default at
  `Finality.lean:107`, or a structure field's default: `Mempool`'s two filters at `Mempool.lean:214,216`, carried
  by `ChainState.mempool := {}` at `Chain.lean:345` into `Reachable.empty` and `staleWitnessState`) is not seen by
  this reading and shows as `·`. [M] 2026-10-14: every call under `lean/BsvChain` passes the span explicitly, and
  `Reachable`'s `pool` step admits any pool. The sentence is on `spec/README.md` beside the count (lane fix-77).
- Script-layer theorems (`lean/BsvScript/**`) are outside #77 and carry no quantification line.
- The pre-existing `ChainContext` closure caveat (`connectionChecks` and `connectionLists` are fixed when the
  context is built, `Chain.lean:400–415`) is unchanged: a theorem over `ctx` quantifies over every context,
  including ones whose closures disagree with `ctx.params`.
