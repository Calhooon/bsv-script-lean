## 2. The second wall: the reader's stack (found by this ladder, fixed in `e7777f8`)

On `7c06091` the 16,000,000-byte step stopped at 0.56 s with "Stack overflow detected. Aborting." (peak 2,497,708,032 B at the
abort) and the 32,000,000-byte step at 0.96 s the same way, where 8,000,000 bytes judged in 1.08 s. Probes on the box
(02:17–02:30 UTC) placed it: the old evaluator overflows on a 16-MB lock over a stack 1,000 deep (0.78 s); the new one
decides one 8,000,007-byte push (`OP_PUSHDATA4`) valid in 0.74 s and 8,000,001 `OP_NOP`s valid in 0.68 s, and overflows on
16,000,007 bytes and 16,000,001 `OP_NOP`s: the size of the lock, whatever its opcodes, so the reader, not the machine.
`Tx.hexDecodeChars` recurses once per byte before it conses; `Bsvs.Corpus.hexDecodeCharsTR` is its loop, proven equal
(`hexDecodeCharsTR_eq`) and substituted at every call compiled after the reader's module (`hexDecodeChars_eq_fast`,
`hexDecode_eq_fast`, `@[csimp]`); `Tx.lean` does not move (it is S2's file). The same 16-MB step on the Studio after the
fix: valid in 4.95 s at 1,427,685,376 B.

**The reach on the box `[M]`: a 255,999,976-byte lock, judged valid on the block path in 29.83 s at a peak of 21.87 GB.**
The time is linear in the size (7.85 s → 19.75 s → 29.83 s from 64 to 256 MB, the instructions 179 → 371 → 720 × 10⁹); the
peak grows a little faster than the size (5.51 → 9.30 → 21.87 GB, some 85 bytes of peak per lock byte at 256 MB, the reader's
hex string and list of bytes and the stack's 4.65 million elements). The next doubling, 512 MB, would need more than the box's
36 GiB by the same growth `[D on M]`, and was not run. The consensus size class runs to a lock inside a
1,000,000,000-byte transaction (`consensus.h:29`; the script size itself is bounded only by `UINT32_MAX`, `consensus.h:60`):
at 85 to 98 bytes of peak per byte that is some 85 to 98 GB `[D on M]`, beyond the box by 2.2× to 2.5× and inside the standing
light's 128-GiB Modal container. So on the box the evaluator reaches a quarter of the consensus class; the rest is memory,
not time (a gigabyte would take about two minutes at this rate `[D on M]`).
