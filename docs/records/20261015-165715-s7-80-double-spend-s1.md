## Findings

- **The issue's theorem sentence.** "A notification is emitted only for a conflict the detector saw after validation" holds
  literally of the detector's refusals (stage 13) only. All three attempts of the run are stage-5 refusals, before any script
  ran (`checked 0`); the handler checks the conflicting input itself before it notifies
  (`src/double_spend/dsattempt_handler.cpp:149-178,396-421`). `notification_conflict_after_validation` states the true form [D] [X].
- [SRC] [X] **No node at the pin originates `dsdetected`**: it reads, checks, relays and posts a peer's message
  (`src/net/net_processing.cpp:4573-4684`); the issue's "the dsdetected message observed on the wire" for a mempool double spend
  does not occur. The run drives one from a test peer and observes the relay on the wire.
- [SRC] [X] **The blacklist runs on the wall clock** (`system_clock`, `src/double_spend/time_limited_blacklist.h:20-23,74,95`;
  `src/double_spend/dsattempt_handler.cpp:319`): the node's lines carry its mock time while the blacklist held by the
  receiver's wall clock; `setmocktime` cannot age an entry out, so the hour is proven only (`Blacklist.add_hour`).
- **A query answered without the header blacklists the endpoint and records the transaction as notified**
  (`:482-489`, `:761-764`, `:644-649`) [D]: the model's s2 effects `[query, blacklisted, recorded]`; the record has no wire
  observation.
- Readings not executed [D]: the proof's length field is never compared with the transaction (`src/merkleproof.h:105-115`);
  `ValidateDoubleSpends` counts a transaction repeating its own outpoint as its block's double spend
  (`src/double_spend/dsdetected_message.cpp:228-273`); an IPv4-mapped IPv6 address prints as its IPv4 key
  (`src/double_spend/dscallback_msg.cpp:116-130`).
- **Teranode, reading only** (the page's section 5): no `dsdetected`, no attempt handler, no callback; the second spend is
  refused with HTTP 409 and gossiped on the rejected-transaction topic. THE THEOREM has nothing to bind there; the measured
  leg waits on #66's cut 2.
