## 1. What was done

A script evaluator was written in Python (standard library only) from the generated specification
pages and the two design pages, with nothing read from any implementation, then run over sixteen
corpus files and compared with the verdicts the files record. Every function in `cleanroom.py` names
the sentence it implements (`spec/<page>.md:<line>` or `docs/<page>.md:<line>`). A behavior the
pages do not determine is `need("<gap id>")`: in the **strict** column it raises `DocumentGap` and
the entry is `gap`; the labelled **assumed** column fills every gap `cleanroom.GAPS` gives a reading
(the opcode names, five constants, and the readings of the multisig loop, the shift's bit order, the
vector files' limits, the finality comparison, the empty `OP_VERIFY`'s reason, the hybrid key's parity
and the shift-number operand order), each fill named per entry, so that column measures everything
else the pages say.

The command: `python3 harness/cleanroom/run.py --all` `[X local]`. The lane's run: 41 s at a 1-minute
load of 26, above rule 17's 20: named here as the exception. The fix lane's re-run, the run of record:
started 14:04:55 UTC at a 1-minute load of 18.10 (under 20), 42.6 s wall (`time -p`), ended at load
16.85; the edits after it change comment and gap-description strings only, no evaluated line.
