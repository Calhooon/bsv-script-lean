## Why the eras differ `[SRC]`

All at bitcoin-sv v1.2.3 `6504a3af`, `src/script/interpreter.cpp` unless another file is named:

- `1471-1481`: `CScript scriptCode {pbegincodehash, pend};` (the current script from its last OP_CODESEPARATOR) then
  `if(checksigData && IsChronicle(flags)) { ... scriptCode += *checksigData; }`.
- `2338-2342`: `VerifyScript` evaluates the scriptSig with `EvalScript(..., scriptSig, &scriptPubKey, ...)`, so `checksigData` is
  the locking script while the unlock executes.
- `255-263`: `CleanupScriptCode` drops the signature only when FORKID is not used; with 0x41 the scriptCode is left as built.
- So after Chronicle the scriptCode of the reader's CHECKSIGVERIFY is `ad` ++ `51` = `ad51`; before Chronicle (no
  `SCRIPT_CHRONICLE` in the word) it is `ad`.
- `verify_script_flags.cpp:65-69` (at v1.2.3, `src/verify_script_flags.cpp`): from the DAA height the block word carries
  `SCRIPT_VERIFY_NULLFAIL` (also in `PRE_CHRONICLE_MANDATORY_SCRIPT_VERIFY_FLAGS`, `script/standard.h:55-60`);
  `interpreter.cpp:1491-1497`: a failed CheckSig with a non-empty signature returns `SCRIPT_ERR_SIG_NULLFAIL` when
  `EnforceNonMalleability(flags, version)`, which is true for every version without `SCRIPT_CHRONICLE` (`40-44`). So before
  Genesis the signature over `ad51` fails against the scriptCode `ad` and is refused as SIG_NULLFAIL before CHECKSIGVERIFY's
  own failure (c3); after Chronicle a version-2 spend is not held to NULLFAIL, so c2 fails as CHECKSIGVERIFY.
- The unlock contains two non-push opcodes. `2321-2334`: the push-only check applies `if((IsGenesis(flags) &&
  !IsChronicle(flags)) || (IsChronicle(flags) && !IsMalleableTxnVersion(checker.Version())))`; `IsMalleableTxnVersion` is
  `version > 1` (`34-38`). The spends are version 2, so after Chronicle the check does not apply; before Genesis neither branch
  holds for any version. Between Genesis and Chronicle a non-push unlock is refused as `SIG_PUSHONLY` for every version
  (#144's shape A rows xsig-00003/00004), so these two eras are the ones where the example executes.
