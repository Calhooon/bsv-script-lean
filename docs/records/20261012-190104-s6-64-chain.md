## Model and boundaries

[D] `Block.lean` consumes the landed body/header checks, the subsidy, `applyTx`,
finite UTXO maps and script oracle. The connection repeats `checkBlock`,
requires the coins parent pointer, skips genesis transactions, applies the
body context and effective BIP30 gate, derives the block word, then applies
every transaction in order. It checks availability, block BIP68, pre-Genesis
per-transaction and aggregate sigops, sums fees in the sequential views,
bounds the coinbase, and judges the queued script calls before publication.
The serial schedule uses the reused detailed script reason; the queued
schedule uses `blk-bad-inputs`. [SRC] `src/validation.cpp:3021–3117,3290–3719`
at `6504a3af`.

[D] `BlockUndo` contains only non-coinbase spent-coin vectors. The transient
execution receipts are separate, and are never stored in the index's undo.
`applyBlockUndo` performs count checks, reverses transaction/input application,
compares output value/script, detects existing restored coins, honors stored
creation-era pruning and updates the tentative best pointer. `disconnectBlock`
publishes only `ok`; failed or unclean spans are discarded. [SRC]
`src/undo.h:109–112`, `src/processing_block_index.cpp:9–96`,
`src/validation.cpp:2937–2953,4065–4117` at `6504a3af`.

[D] The tree stores the header-derived identifier, parent, height, the reused
fixed-width accumulated work, validity/failure/double-spend flags, optional
body/undo, transaction/link counts, sequence, completion observation and unique
pointer-order rank. The model has no pointer-address oracle. Candidate
comparison uses work, completion, sequence and rank in source order. Body-less
ancestry becomes unlinked; invalid ancestry is removed with its descendants.
Automatic activation disconnects to the fork and connects census-sized runs,
retries invalid candidates, and reports interruption separately from completion.
Explicit invalidation, reconsideration, precious ordering, and effective soft
rejection/freeze transitions are executable. [SRC] `src/block_index.h:41–195,542–589,816–827,954,1073–1077,1225–1274`,
`src/validation.cpp:4413–4800,4913–5330,5528–5725` at `6504a3af`.
