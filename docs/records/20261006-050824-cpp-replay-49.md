## 2. The projection (`tools/cpp_replay.py`, new)

The C++ entries are interpreter calls, not spends; the drivers judge spends. `project` writes, per file of `corpus/cpp`, the
entries that have a faithful spend form into `corpus/cpp/replay/cpp-<stem>/cases.jsonl` with `cases-manifest.json`, and a
`ledger.json` naming every other entry's reason (a file with no spend form has the ledger alone). The forms: an `EvalScript`
call as a spend whose unlocking script rebuilds the call's stack by minimal pushes; a `VerifyScript` call (its unlocking script
spliced into its own one-input transaction, or on a transaction built for it under a checker whose signature checks all fail);
`CheckInputs` (the transaction and its coins); `CScriptCheck` (input 0 of a one-input transaction). Each carries the call's
word as its explicit `flags`, `params.consensus` true, the coin's height in the era its UTXO bits name (600,000; 700,000;
950,000), and the unit's verdict as a spend verdict under `sv-node-unit@v1.2.2` (what the check asserts) and
`sv-node-unit-observed@v1.2.2` (what the instrumented build returned). The rules of faithfulness are in the tool's header and
`project_one`; three were found by the judge in this sitting and fixed before the run of record (§5).

The three largest projections are committed gzipped (`gzip -9 -n`): `cpp-opcode` (plain 249 MB), `cpp-script` (63 MB),
`cpp-txvalidationcache` (50 MB); `corpus/cpp/replay/.gitignore` names their plain forms; `rules_check` reads a `.gz` beside a
manifest's path through `gzip -dc` (this sitting's patch, §6).

record, never adjusted in a verdict: (a) `multisig_tests` calls `VerifyScript` with the unlocking script as an argument while
the transaction's own input script is empty; the projection used the transaction as written, so spec and node both said

`script_tests.cpp:3171-3343`); the projection now splices the unlocking script into the input. (b) `script_tests.cpp:4898-4987`
call `EvalScript` under FORKID without STRICTENC; `VerifyScript` adds STRICTENC under FORKID, so the spend failed with

calls are undecided by name. (c) a `script_P2SH_tests` call with amount −1 stopped the evaluator (`satoshis: Natural number
