# Changelog

Every edition of this repository, the newest at the top, in the form of [Keep a Changelog](https://keepachangelog.com/en/1.1.0/);
the versions follow [Semantic Versioning](https://semver.org/spec/v2.0.0.html). An entry names its date (UTC), the release of
bitcoin-sv it is pinned to (`docs/PROVENANCE.md` section 1a), what it added, and the tripwire record (`make check`) of its
tagged commit under `docs/records/`.

The public repository starts with a fresh history: the editions before v1.2.0 were tagged in the private history, so a
commit named below is "commit <sha> of the private history", a name to match against a record, not a link. From v1.2.0
on, a tag's commit adds only its tripwire record, so the record named by an entry checked the tree the tag points to.

## [1.2.0] - 2026-10-26

The public edition, born 2026-10-21 with a fresh history and public since 2026-10-26 as the tag `v1.2.0`; the GitHub release
carries this entry. Pinned to bitcoin-sv v1.2.3 (`6504a3aff65ba97c0f6c80962b033e35ecbfed4b`).

### Added

- The entry pages for a stranger: `README.md` for four readers, the front door `docs/README.md` with one reading path per
  reader, the module map `lean/README.md`, the glossary `docs/GLOSSARY.md`, and `docs/STATE-OF-THE-WORLD.md` as a plain
  status page, each claim with its record.
- `make verify`, the four commands of the README's "Verify the base" in one target; its run on the build machine is
  `docs/records/20261021-150738-verify-pub-lean.md`.
- The contributor pages: `CONTRIBUTING.md`, `SECURITY.md`, the divergence report template
  (`.github/ISSUE_TEMPLATE/divergence.md`) and the page for a contributor's coding agent.
- The indexes: `tools/README.md` (every file of `tools/`, generated by `tools/tools_index.py`), `make help` (the default
  goal: every target by group), `docs/records/INDEX.md` (every record, generated by `tools/records_index.py`, refused
  stale by the seed leg of `make check`) and this changelog.

### Changed

- The labels `[M]` `[X]` `[D]` `[LIT]` `[EST]` `[SRC]` stand in records, claim tables and provenance pages; the prose of
  the entry pages cites its record path instead.
