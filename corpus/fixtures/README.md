[M] The signer files cover every row of `corpus/signer/*.jsonl`. `fixtures_signer.py` invokes the self-check's
`signer_gen --sign` path over the corpus's test keys and per-site `scriptcode_hex`. Each control txid and site
digest must equal the control column in `20261016-203024-s3-145d-signer-column-{go-sdk,ts-sdk}-s3.json`.
SDK refusals use that record's hex where present, otherwise the current adapter regenerates it and must match
the recorded txid and site traces. Both TypeScript API methods are retained for SINGLE even when their bytes
match. `source` (Go) and `notes` (TypeScript) name the record, method and signer class; those fields do not
affect the SDK's assertions. All 241 controls have recorded node verdicts; the spec-only fallback count is zero.
An unrecorded row is evaluated through the self-check's evaluator path and explicitly labeled as a spec verdict.
The immutable records are read locally, falling back to `git show` at `019a4a9c435cd1bdb60da6228fae891e230ee6d5`
when the signer-column stack has not landed; their SHA256 values are checked. No fetch or install occurs.

signer controls, the existing crypto.checksig.unlock.ungated predicate described below. Other unclassified
differences are RED.

[D] `make fixtures-proof` requires both classifier GREEN verdicts and seven nonempty summaries matching the manifest.
It preserves child failures, names missing tools with SKIPPED BY NAME, and prints `record:` for its JSON receipt.
The receipt retains commands, pins, counts, statuses and complete logs. Set `RULES_CHECK_BIN` to use an already-built
classifier, `GO_BIN` for Go, or `TS_ADAPTER_DIR` for an installed adapter with a byte-equal package lock. The current
proof source is always used. Receipts default to `<lanes-volume>/out/bsv-script-lean/fixtures-proof/` when available,
otherwise `~/bsv/targets/fixtures-proof/`; `FIXTURES_PROOF_OUT` overrides that parent. No dependency install is run.

verifier difference. Both verifiers reject every exported SDK refusal; this replay adds no verifier finding.
