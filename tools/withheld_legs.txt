# tools/withheld_legs.txt (bsv-script-lean archived #116, 2026-10-18): what the hosted gate does NOT run, by name.
# A hosted runner holds the public tree and nothing else: no pinned upstream clone, no built node, no node, no box. The
# legs it runs skip those reads BY NAME (never a pass), as in the Modal container (`CONTRIBUTING.md`, "What never enters"). What
# they skip is run on the box, and the box posts the result on the commit as the status `box/withheld-legs`
# (tools/box_status.sh), the one gate on these rows in the branch protection.
# Read by tools/withheld_legs.py: `--declare` (the workflow's withheld-legs job prints this list and matches the families
# against tools/export_withheld.txt) and `--judge <record>` (tools/box_status.sh reads the box's tripwire record).
# One row per line, five fields split by ` | `:
#   name | families | evidence | refused | why
#   families  the groups (`## <group>:`) of tools/export_withheld.txt whose withheld material comes from this row's runs,
#             comma-separated; `-` when the row withholds no file (it is withheld for the host it needs, not for a page)
#   evidence  the verdict lines (regular expressions, `&&` between them) the box's tripwire record must carry for the row
#             to count as run; `on-demand` when the tripwire runs no step of the row (its runs have their own records,
#             and the public legs replay the answers those runs recorded)
#   refused   a regular expression that must NOT match any of those lines (the box itself skipped the read); `-` for none
