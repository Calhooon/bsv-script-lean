# tools/secrets_patterns.txt (S3, lane gate-135, #135; [M] 2026-10-14): the shapes the secrets scan refuses.
# ONE FILE, TWO ENGINES: tools/secrets_scan.sh hands these rules to gitleaks at its pin (a generated config, the default
# rule set OFF) and to tools/secrets_scan.py (the Python engine where gitleaks is absent); both read only this file and
# tools/secrets_allow.txt, so the two engines judge the same rules.
# FORMAT: `<rule-id><TAB><regex>[<TAB><keywords>]`, one rule per line; `#` comments and blank lines skipped. A regex stays
# inside the common subset of Python's `re` and Go's RE2 (no lookaround, no backreference; `(?i)` only as the leading
# flag; no class that admits a newline). The keywords (lowercase, comma-separated) are gitleaks's prefilter: a rule runs
# only on a text that holds one of them, case ignored; a rule without keywords runs on every text.
# SHAPES ONLY: every rule is a public vendor's documented prefix or a structural form; no value of any credential is
# written here or anywhere in this tree, and the self-test (tools/secrets_scan.py --self-test) assembles its fake
# samples from fragments at run time so the tree never carries a literal sample either.

# the project's own services, by their public key shapes: the crates.io token (prefix `cio`, 32 alphanumerics), Modal's
# token pair (`ak-` id, `as-` secret), the ARC/TAAL API key (`mainnet_` or `testnet_`, 32 lowercase hex)
crates-io-token	\bcio[A-Za-z0-9]{32}\b	cio
modal-token	\ba[ks]-[A-Za-z0-9]{20,}\b	ak-,as-
taal-api-key	\b(mainnet|testnet)_[0-9a-f]{32}\b	mainnet_,testnet_
# the chain's own secrets: a WIF private key (mainnet `5`, `K` or `L`; testnet `9` or `c`, base58) and an extended private key
wif-private-key	\b[5KL9c][1-9A-HJ-NP-Za-km-z]{50,51}\b
extended-private-key	\b[xt]prv[1-9A-HJ-NP-Za-km-z]{100,112}\b	xprv,tprv
# structural forms: credentials inside a URL; a secret-named variable assigned a long literal
url-credentials	\b[a-z][a-z0-9+.-]{1,20}://[A-Za-z0-9._~%-]{1,64}:[A-Za-z0-9._~%!$&*+,;=-]{6,128}@[A-Za-z0-9.-]+	://
secret-assignment	(?i)\b[a-z0-9_]*(api_?key|access_?key|secret(_?key)?|token|passw(or)?d|private_?key)["']?[ \t]*[:=][ \t]*["']?[A-Za-z0-9+/_.=-]{24,}	key,secret,token,passw
